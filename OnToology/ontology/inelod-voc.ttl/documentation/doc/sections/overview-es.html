INELOD VOC: Resumen volver a índice

Esta sección ofrece una panorámica de la arquitectura conceptual de INELOD VOC antes de entrar en el detalle de cada término en la sección de referencia cruzada. La ontología no propone un modelo nuevo de cubo estadístico: se apoya íntegramente en el modelo abstracto de la RDF Data Cube Vocabulary (QB) del W3C y se limita a especializar las propiedades concretas que el INE necesita para sus operaciones.

Patrón de modelado: dimensiones y medidas como subpropiedades

En INELOD VOC cada propiedad pertenece, conceptualmente, a uno de estos dos roles:

  1. Propiedades de dimensión: se declaran como owl:ObjectProperty con dominio qb:Observation, lo que las identifica como ejes de desagregación de cualquier observación de un cubo. Cuando la dimensión es una de las cinco dimensiones genéricas SDMX (refArea, refPeriod, age, currency, educationLev), la propiedad ine se declara además como rdfs:subPropertyOf de la dimensión SDMX correspondiente, garantizando interoperabilidad descendente con consultas SDMX-RDF.
    Ejemplo: ine:cities rdfs:subPropertyOf sdmx-dimension:refArea; ine:childsAge rdfs:subPropertyOf sdmx-dimension:age.
  2. Propiedades de medida: se declaran como owl:ObjectProperty y, salvo excepciones, como rdfs:subPropertyOf sdmx-measure:obsValue. Esto permite a cualquier consumidor genérico de datos QB/SDMX recuperar el valor observado sin conocer la propiedad específica.
    Ejemplo: ine:births, ine:deathsPerThousandInhabitants, ine:cubicMetres.

Adicionalmente, INELOD VOC incorpora la clase auxiliar ine:MeasureSet y la propiedad ine:inMeasureSet, cuyo rango es esa clase, para agrupar explícitamente medidas relacionadas (por ejemplo, todas las medidas monetarias o todas las medidas demográficas relativas a 1.000 habitantes). Esta agrupación complementa al mecanismo nativo de QB (qb:MeasureProperty dentro de qb:DataStructureDefinition) y resulta útil para construir interfaces de exploración en los portales de datos.

Vocabularios reutilizados

Siguiendo la recomendación FAIR de maximizar la reutilización (Wilkinson et al., 2016, Scientific Data), INELOD VOC reutiliza:

  • QB (RDF Data Cube Vocabulary) como modelo abstracto de cubo estadístico.
  • SDMX-Dimension y SDMX-Measure para alinearse con el estándar SDMX/ISO 17369.
  • SKOS como rango de varias propiedades de dimensión cuyas categorías son listas controladas (por ejemplo, comunidades autónomas, sectores económicos, países).
  • FOAF para anotaciones personales (nombre, apellido) reutilizadas como subpropiedades.
  • DCMI Metadata Terms para la metainformación de la ontología (dct:title, dct:creator, dct:description, dct:created, dct:modified).
  • VANN para declarar el prefijo y espacio de nombres preferidos.
  • QUDT para tipar el rango de propiedades cuyo valor es un porcentaje (qudt:PERCENT).
  • Creative Commons (cc) para declarar la licencia, que es CC BY 4.0.
